# Sample Flight Log Structure

This repository does not include real flight logs.

Supported user-supplied log formats:

- PX4 ULog files: `.ulg`
- CSV exports with attitude, position, battery, and actuator columns
- JSON telemetry snapshots generated by this project

Recommended private runtime layout:

```text
runtime-data/
├── uploads/
│   └── ulg/
├── downloads/
│   └── ulg/
├── reports/
├── logs/
└── data/
    └── flight_case_library.json
```

Do not commit real logs, test-site coordinates, aircraft serial numbers, mission files, or parameter backups.
