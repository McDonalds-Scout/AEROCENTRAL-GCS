# AeroCentral Desktop Application

This directory adds a desktop application layer on top of the existing Web UI and Python backend.

The Web development workflow is preserved:

```powershell
.\start-ui.cmd
```

The desktop workflow uses Electron:

```text
AeroCentral.exe
  -> starts ground_station_server.exe
  -> waits for http://127.0.0.1:8080/api/version
  -> opens the existing Web UI inside an Electron window
  -> optionally starts MAVLink connection from app_config.json
```

## Runtime Modes

Development mode:

- Electron runs from `desktop/electron`.
- Backend is started with local Python.
- UI is loaded from `http://127.0.0.1:<port>/`.

Production mode:

- Electron runs as `AeroCentral.exe`.
- Backend is loaded from Electron resources: `resources/backend/ground_station_server.exe`.
- Runtime data is written to Electron `userData`.
- No Python, Node.js, or project dependencies are required on the user's machine.

## Desktop Menu

The desktop shell adds:

- File: Open Log, Export Report, Settings, Exit
- Connection: Connect PX4, Disconnect, Select Port
- Tools: Parameter, Calibration, Mission, Actuator Test
- Help: Runtime Data Folder, About

Menu actions navigate to the existing UI pages or call the existing backend APIs.

## MAVLink Auto Connect

Auto-connect is implemented but disabled by default for safety. Enable it in the runtime config file:

```json
{
  "mavlink": {
    "autoConnect": true,
    "type": "serial",
    "serialPort": "COM3",
    "baud": 115200
  }
}
```

For UDP target mode:

```json
{
  "mavlink": {
    "autoConnect": true,
    "type": "udp",
    "targetIp": "127.0.0.1",
    "targetPort": 14550
  }
}
```

Do not commit real aircraft IP addresses or private test configuration.

## Build Windows Desktop Package

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\desktop\electron\build_desktop_windows.ps1 -Version 0.1.0
```

Outputs:

```text
dist\AEROCENTRAL\                 # PyInstaller backend executables
dist\desktop\                     # Electron installer and portable app
```

The final installer is generated by electron-builder under `dist/desktop`.

## Verify Desktop Runtime

Development smoke test:

```powershell
cd .\desktop\electron
pnpm run smoke
```

Force Electron to start its own backend instead of reusing an existing Web server:

```powershell
pnpm run smoke:own
```

Packaged smoke test:

```powershell
.\dist\desktop\win-unpacked\AeroCentral.exe --smoke-test
```

Use a temporary config file for automated checks:

```powershell
.\dist\desktop\win-unpacked\AeroCentral.exe --smoke-test --force-own-backend --aerocentral-config=C:\path\to\app_config.json
```

The smoke output includes the backend URL, config file path, configured port, and `/api/version` payload.

## User Configuration

At runtime the desktop app creates:

```text
%APPDATA%\AeroCentral\app_config.json
```

The Settings menu opens this file. Keep `mavlink.autoConnect` disabled until the aircraft connection settings are confirmed. For normal operation, select the USB serial port or UDP link inside the existing connection UI.
